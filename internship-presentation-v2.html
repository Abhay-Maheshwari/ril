Project 01 — Architecture & Security
Backend, Infra
& Security
Security Audit Work
  • AES-256-CBC Encryption — All visitor PII encrypted at rest with transparent decryption layer for emails
  • HP Fortify Remediation — SecureRandom migration, catch blocks refactored, logs sanitized, creds removed
  • Clickjacking Defense — X-Frame-Options + CSP 'self' + JS frame-busting (no single point of failure)
  • SonarQube (50+ Smells) — Unused DTOs removed, ternaries extracted, code deduplicated, custom exceptions
  • BlackDuck OSS (0 Issues) — npm overrides forced safe versions for transitive CVEs (tar, micromatch, etc.)
  • K8s Secrets Migration — Hardcoded credentials replaced, secrets externalized across dev/QA/prod
Infrastructure & DevOps
  • Azure Pipelines CI/CD — automated builds with multi-environment replication (dev, QA, prod)
  • ConfigMap Repos — created from scratch (PC_SB_VMS_ConfigMap, PC_AJ_ConfigSetup)
  • bootstrap.yml Migration — ConfigMap values injected before Spring application context init
  • Kubernetes 503 Fix — traced to spring.application.name mismatch in ConfigMap
  • Istio VirtualService — double-slash rewrite fix, match block alignment
  • HTTPS ↔ HTTP — normalization across dev and QA environments
Backend Engineering
  • RBAC Harmonization — unified numeric and string role checks across all services
  • Spring @Cacheable — on Company / Warehouse / Zone, eliminated N+1 query pattern
  • Jakarta Validation — @Pattern, @NotBlank, @Email, @Positive across every input DTO
  • JWT Claims — sidebar data moved to JWT, eliminated redundant DB calls on every request
  • Fail-safe Pattern — Left Join with "unknown" fallback prevents null pointer crashes
  • Redis Integration — caching layer for high-volume data retrieval endpoints

Real Problems
Challenges
Solved
OTP Dual-Mode FailureSMS and email channels were generating separate transaction IDs in "both" mode — users entering the OTP from one channel failed verification against the other. Unified to a single shared token.
PII Encryption vs EmailAES-256 encrypted visitor data broke email notifications (recipients got ciphertext). Built a transparent decryption layer before the notification pipeline while keeping storage encrypted.
Clickjacking Security GapRisk discovered during security testing. Implemented defense-in-depth using `Content-Security-Policy (frame-ancestors)`, `X-Frame-Options`, and frontend frame-busting safeguards.
AD Lookup ReliabilityInternal visitor creation depended on corporate AD, but lookups could fail intermittently. Added resilient fallbacks and exception handling so the flow remains usable during directory instability.
CMS QA-Only Image FailuresMedia worked in Dev but failed in QA. Audited 4+ repos and fixed APIM path malformations, bucket-source mismatches, and cross-env config drift.
Image Quality vs PerformanceClient-side compression improved speed but degraded visual quality. Re-tuned the image pipeline (`ImageCompressionService` + lazy loading) for quality-first behavior without losing performance.
Section Reorder PersistenceDrag-and-drop edits looked saved but reset after reload on key sections. Fixed backend persistence and initialization-order conflicts so admin reorder changes remain stable.
Strapi No-Change LoopAdmin edits were not reflecting on frontend due to `data[].attributes` mapping gaps, slug mismatches, and cache invalidation misses. Patched all three to restore reliable content updates.
